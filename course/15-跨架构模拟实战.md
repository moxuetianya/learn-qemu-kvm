# 15 · 跨架构模拟实战

> 在 x86 上跑 ARM/MIPS/PowerPC VM，做嵌入式开发、测试、二进制分析。

## 学习目标

- 知道 TCG 是 QEMU 的软件模拟核心
- 能拉起 ARM / MIPS / RISC-V 客户机
- 理解交叉编译和 sysroot
- 知道 aarch64 与 x86_64 的 VM 体验差异

## 1. QEMU 的两种模式

| 模式 | 加速 | 何时用 |
| --- | --- | --- |
| **KVM** | 硬件 | 同架构生产 |
| **TCG** | 软件（动态翻译） | 跨架构 / 无 KVM |

TCG = Tiny Code Generator。QEMU 把客户机指令「翻译」成主机指令执行。

```
x86 客户机指令 ──► TCG ──► x86 host 指令（跑在 CPU 上）
ARM 客户机指令 ──► TCG ──► x86 host 指令（跑在 CPU 上）
```

**性能**：比原生慢 5-50 倍，但**足够跑测试**。

## 2. 跨架构模拟典型场景

| 场景 | 架构 | 工具 |
| --- | --- | --- |
| ARM Linux 开发 | aarch64 | qemu-system-aarch64 |
| ARM 单片机仿真 | cortex-m | qemu-system-arm |
| MIPS 路由器 | mipsel | qemu-system-mipsel |
| RISC-V 实验 | riscv64 | qemu-system-riscv64 |
| PowerPC 服务器 | ppc64 | qemu-system-ppc64 |

## 3. ARM 客户机实操

### 3.1 拉取镜像

```bash
wget https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/aarch64/alpine-virt-3.20.3-aarch64.iso
wget https://cloud.debian.org/images/cloud/bookworm/daily/latest/debian-12-generic-arm64.qcow2
```

### 3.2 启动

```bash
qemu-system-aarch64 \
    -machine virt,accel=tcg,gic-version=3 \
    -cpu cortex-a72 \
    -m 2G -smp 2 \
    -drive file=alpine-virt-3.20.3-aarch64.iso,media=cdrom,readonly \
    -drive file=alpine-arm.qcow2,format=qcow2,if=virtio \
    -netdev user,id=n0 \
    -device virtio-net-pci,netdev=n0 \
    -device virtio-gpu-pci \
    -bios /usr/share/qemu-efi/QEMU_EFI.fd \
    -vnc :0
```

### 3.3 注意

- `-bios` 必须给 UEFI，ARM 多数用 UEFI
- `-cpu` 选具体型号（cortex-a53 / a72 / a76）影响指令集
- `virtio-net-pci` 在 ARM 是 `pci`，不是 `mmio`

## 4. MIPS 客户机

```bash
qemu-system-mipsel \
    -machine malta \
    -cpu 24Kc \
    -m 256 \
    -drive file=debian-mipsel.qcow2,format=qcow2 \
    -netdev user,id=n0 \
    -device e1000,netdev=n0 \
    -nographic
```

> 老路由器、IoT 设备仿真常用。

## 5. RISC-V 客户机

```bash
qemu-system-riscv64 \
    -machine virt \
    -cpu rv64 \
    -m 2G -smp 4 \
    -bios /usr/share/qemu-efi/QEMU_EFI.fd \
    -drive file=fedora-riscv.qcow2,format=qcow2,if=virtio \
    -device virtio-gpu-pci \
    -device virtio-net-pci,netdev=n0 \
    -netdev user,id=n0 \
    -nographic
```

Fedora / openEuler 已经发布 RISC-V 镜像。

## 6. 性能对比

| 架构 | 与 x86 原生比 |
| --- | --- |
| ARM64 | 5-15x 慢 |
| ARM32 | 10-30x 慢 |
| MIPS | 20-50x 慢 |
| RISC-V | 5-20x 慢 |
| PowerPC | 10-30x 慢 |

> 跨架构只适合开发 / 测试，不要跑生产业务。

## 7. user-mode 模拟

```bash
# 在 x86 主机跑 ARM 二进制
qemu-aarch64 -L /usr/aarch64-linux-gnu ./arm-app
# -L 是 lib path

# 跑 MIPS
qemu-mipsel-static ./mips-app
```

`qemu-user` 是 `binfmt_misc` 的好搭档：

```bash
sudo apt install qemu-user-static binfmt-support
# 注册 binfmt 后
docker run --rm --platform linux/arm64 alpine uname -m
# 输出 aarch64
```

## 8. 嵌入式仿真

### 8.1 STM32（裸机）

```bash
qemu-system-arm \
    -machine stm32vldiscovery \
    -cpu cortex-m3 \
    -nographic \
    -kernel stm32-firmware.elf \
    -semihosting
```

> semihosting 让裸机程序能用 printf 通过 host stdout。

### 8.2 Raspberry Pi

```bash
qemu-system-aarch64 \
    -machine raspi3b \
    -cpu cortex-a53 \
    -m 1G \
    -drive file=raspbian.img,format=raw,if=sd \
    -netdev user,id=n0 \
    -device usb-net,netdev=n0
```

## 9. 工具链与调试

### 9.1 交叉编译

```bash
sudo apt install gcc-aarch64-linux-gnu

aarch64-linux-gnu-gcc -o hello hello.c

qemu-aarch64 -L /usr/aarch64-linux-gnu ./hello
# Hello, World!
```

### 9.2 GDB 远程调试

```bash
# qemu 启动加 -s -S
qemu-system-aarch64 -s -S ...

# gdb 另一终端
gdb-multiarch
(gdb) file hello.elf
(gdb) target remote :1234
(gdb) b main
(gdb) c
```

## 10. 优劣对比：跨架构虚拟化方案

| 方案 | 性能 | 兼容性 | 易用 |
| --- | --- | --- | --- |
| QEMU TCG | ★ | ★★★★ | ★★★ |
| QEMU + 翻译缓存 | ★★ | ★★★★ | ★★★ |
| Apple Silicon (Rosetta) | ★★★★★ | ★★ | ★★★★★ |
| AWS Graviton | ★★★★★ | ★★★ | ★★★ |
| 服务器 Graviton3 | ★★★★★ | ★★★★ | ★★★ |

> 当 ARM 上有原生硬件（AWS Graviton、Apple Silicon）时，**别用 x86 + QEMU 跑 ARM 业务**。

## 11. 实战操作

### 11.1 跑一台 ARM Alpine

```bash
wget https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/aarch64/alpine-virt-3.20.3-aarch64.iso

qemu-img create -f qcow2 alpine-arm.qcow2 4G

qemu-system-aarch64 \
    -machine virt,accel=tcg \
    -cpu cortex-a72 \
    -m 1G -smp 2 \
    -bios /usr/share/qemu-efi/QEMU_EFI.fd \
    -drive file=alpine-virt-3.20.3-aarch64.iso,media=cdrom,readonly \
    -drive file=alpine-arm.qcow2,format=qcow2,if=virtio \
    -netdev user,id=n0 \
    -device virtio-net-pci,netdev=n0 \
    -vnc :0
```

### 11.2 跑用户态 ARM 二进制

```bash
sudo apt install qemu-user-static
echo '#!/bin/bash' > /tmp/hello.sh
echo 'qemu-aarch64-static /bin/uname -m' > /tmp/hello.sh
chmod +x /tmp/hello.sh
# /tmp/hello.sh 输出 aarch64
```

### 11.3 Docker 多架构镜像

```bash
docker run --rm --platform linux/arm64 alpine uname -m
# aarch64
```

## 12. 小结

- TCG 是软件模拟，足够跑嵌入式 / 测试
- ARM 镜像要用 UEFI 启动
- 交叉编译 + qemu-user-static 是开发利器
- 生产 ARM 业务用原生 ARM 硬件
