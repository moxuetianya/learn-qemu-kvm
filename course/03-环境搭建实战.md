# 03 · 环境搭建实战

> 本章是第一个「动手」章节。学完你应该能解释每个安装步骤在做什么。

## 学习目标

- 理解 QEMU / KVM / libvirt 三者的关系
- 能在三种发行版（Ubuntu/Debian、RHEL、openEuler）上装好
- 知道「嵌套虚拟化」是什么、怎么开
- 知道何时需要编译 QEMU 而不是用发行版包

## 1. 三层工具栈

```
┌─────────────────────────────────────┐
│  工具（你日常用）                       │
│  virt-manager / virsh / virt-install  │
│  qemu-system-x86_64 / qemu-img        │
├─────────────────────────────────────┤
│  管理层（API）                          │
│  libvirt（屏蔽不同 hypervisor 差异）     │
├─────────────────────────────────────┤
│  虚拟化执行层                           │
│  QEMU（用户态）+ KVM（内核态）           │
├─────────────────────────────────────┤
│  内核                                │
│  Linux 6.x（含 kvm.ko kvm_intel.ko）   │
├─────────────────────────────────────┤
│  硬件（CPU VT-x / EPT / IOMMU）         │
└─────────────────────────────────────┘
```

**QEMU + KVM** 是引擎；**libvirt** 是「说明书」；**virt-manager/virsh** 是「方向盘」。

> **常见误区**：QEMU 不是 KVM 的替代品，它们是协作关系。  
> 早期没硬件辅助时 QEMU 自己跑（TCG 模式，纯软件）；现在 KVM 加速，QEMU 退居「设备模拟 + 管理」。

## 2. 安装前的检查清单

| 检查 | 命令 | 必须 |
| --- | --- | --- |
| CPU 支持 VT-x/AMD-V | `egrep -c '(vmx\|svm)' /proc/cpuinfo` | > 0 |
| 内核 ≥ 4.4 | `uname -r` | 建议 5.4+ |
| 系统支持 KVM | `ls -l /dev/kvm` | 文件存在 |
| 磁盘空间 | `df -h /var` | ≥ 50G |
| 内存 | `free -h` | ≥ 4G 空闲 |

## 3. 安装步骤（按发行版）

### 3.1 Ubuntu 22.04 / Debian 12

```bash
sudo apt update
sudo apt install -y \
    qemu-system-x86 qemu-system-arm qemu-utils \
    qemu-kvm libvirt-daemon-system libvirt-clients \
    bridge-utils virt-manager virt-viewer \
    ovmf genisoimage cloud-image-utils \
    libguestfs-tools

sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt,kvm $USER
# 重新登录
```

### 3.2 RHEL 9 / Rocky 9 / AlmaLinux 9

```bash
sudo dnf install -y qemu-kvm qemu-img libvirt virt-install \
                    virt-manager virt-viewer libguestfs-tools \
                    bridge-utils edk2-ovmf genisoimage

sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt $USER
```

### 3.3 openEuler 22.03 / 欧拉

```bash
sudo dnf install -y qemu qemu-img libvirt virt-install \
                    virt-manager virt-viewer \
                    libguestfs libguestfs-tools \
                    bridge-utils edk2-ovmf
```

### 3.4 通用：检查安装结果

```bash
qemu-system-x86_64 --version | head -1
virsh --version
libvirtd --version
systemctl status libvirtd
virsh nodeinfo
```

## 4. 嵌套虚拟化

> 「VM 里再开 VM」叫嵌套虚拟化。在云主机里练手必备。

### 4.1 Intel

```bash
# 当前
cat /sys/module/kvm_intel/parameters/nested
# Y 已开，N 未开

# 打开
sudo modprobe -r kvm_intel
sudo modprobe kvm_intel nested=1

# 持久化
echo 'options kvm_intel nested=1' | sudo tee /etc/modprobe.d/kvm.conf
```

### 4.2 AMD

```bash
sudo modprobe -r kvm_amd
sudo modprobe kvm_amd nested=1
echo 'options kvm_amd nested=1' | sudo tee /etc/modprobe.d/kvm.conf
```

### 4.3 在 VM 里验证

VM 启动后跑 `egrep -c '(vmx|svm)' /proc/cpuinfo` 应该非 0。

## 5. 何时需要编译 QEMU

| 场景 | 是否需要编译 |
| --- | --- |
| 跑通用 Linux/Windows VM | ❌ 系统包够用 |
| 需要新 CPU model（如 Icelake-Server v4） | ✅ |
| 调试 QEMU 源码 | ✅ |
| 减小体积（去掉不需要的架构） | ✅ |
| 装到嵌入式交叉工具链 | ✅ |

### 快速编译

```bash
git clone https://git.qemu.org/git/qemu.git
cd qemu
git checkout v8.2.0       # 锁版本

./configure --target-list=x86_64-softmmu \
            --enable-kvm \
            --enable-virtfs \
            --enable-spice

make -j$(nproc)          # 5-10 分钟
sudo make install
```

## 6. 网络默认环境

装完 libvirt 默认会创建 `virbr0`（NAT 桥）：

```bash
ip addr show virbr0
# 4: virbr0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
#     inet 192.168.122.1/24

brctl show
# bridge name     bridge id           STP enabled     interfaces
# virbr0          8000.525400xxxxxx  yes             virbr0-nic
```

默认 VM 通过 `virbr0` NAT 上网。如果你要让 VM 暴露到内网，得手工桥接（详见 08 章）。

## 7. 优劣对比：装包 vs 编译 vs 容器

| 维度 | 系统包 | 编译 | 容器 |
| --- | --- | --- | --- |
| 安装时间 | 5 分钟 | 10-30 分钟 | 1 分钟 |
| 稳定性 | ✅ 高 | ⚠️ 自己背锅 | ✅ |
| 新特性 | ❌ 滞后 | ✅ 最新 | ✅ |
| 调试源码 | ❌ 看不到符号 | ✅ | ⚠️ 要带源码 |
| 跨主机一致 | ❌ | ❌ | ✅ |

> **生产建议**：跑业务用系统包；研发 / 实验室可编译或用容器。

## 9. 小结

- **QEMU + KVM 是引擎，libvirt 是说明书**
- 优先用系统包，研发可编译
- **嵌套虚拟化**在云主机里学 KVM 必备
- `virbr0` 是 libvirt 默认 NAT 网络
