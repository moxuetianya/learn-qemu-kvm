# 00 · 课程介绍与学习方法

> 5 分钟读完，省你后面走弯路。

## 这门课解决什么问题

虚拟化的资料分两类：

1. **理论书** —— 大段大段讲 VMCS / EPT / I/O 虚拟化，看完还是不知道怎么开一台 VM
2. **操作手册** —— `qemu-system-x86_64 -enable-kvm ...`，看不懂这串参数在干嘛

这门课走中间路线：

- **理论够用**：每个抽象都告诉你「为什么这样设计、不这样会怎样」
- **实战够多**：每章都带实验，跑得起来、看得到结果
- **源码够读**：在能动手的基础上再深入 Linux KVM 子系统代码

## 学习方法

### 三种身份三种读法

| 你是 | 重点章节 | 跳过 |
| --- | --- | --- |
| 运维 / SRE | 03、07、08、09、11、12、13、19 | 16、17 |
| 内核 / 系统开发 | 06、16、17、lab10 | – |
| 学生 / 转岗 | 全部按顺序 | – |

### 怎么读这章

每章都是这个结构（不变）：

1. **学习目标** —— 一句话 + 几个问题自测
2. **理论要点** —— 讲清楚是什么
3. **优劣对比** —— 每种方案讲生产环境怎么取舍
4. **实战操作** —— 真实命令、真实输出
5. **小结** —— 一张图或一段话
6. **思考题** —— 主动回忆
7. **参考资料** —— `refs/learn-kvm/` 原文链接

### 怎么动手

不要只读，每章对应的 `labs/` 都跑一遍。建议：

- **第一步**：把 `labs/scripts/` 里所有 `.sh` 全部通读一遍
- **第二步**：从 `lab01` 开始跑，跑不通看 19 章排错
- **第三步**：把跑通的环境保存为基线镜像（`lab03` 会教你）

## 常见误区

> 我看完书就会了？
> —— 不会。虚拟化是工程学科，必须动手。

> 我把所有章节顺序读完才动手？
> —— 不要。读到第 5 章就开始动手，中间穿插回去补理论。

> 我跳过理论直接照抄命令？
> —— 排错时一定后悔。每一段命令都对应一段原理。

> 教程里说 QEMU 等于「用户态」、KVM 等于「内核态」，是不是太简化了？
> —— 是。这是教学上的简化。完整描述看 04 章末「常见误区」。

## 你需要的机器

| 项 | 最低 | 推荐 |
| --- | --- | --- |
| CPU | Intel VT-x 或 AMD-V | 多核带 AES-NI |
| 内存 | 8 GB | 16 GB+（要做嵌套虚拟化） |
| 磁盘 | 30 GB 空闲 | 100 GB+（qcow2 实际占用可缩） |
| OS | Ubuntu 22.04 / Debian 12 / RHEL 9 | – |

## 你需要的工具

```bash
# 必装
qemu-system-x86 qemu-utils qemu-efi       # QEMU
qemu-kvm                                  # Debian/Ubuntu 风格包名
libvirt-daemon-system libvirt-clients     # libvirt
virt-manager                              # GUI（可选）
virt-viewer                               # 远程桌面查看
ovmf                                      # UEFI 固件

# 调试用
gdb strace ltrace perf bpftrace
```
