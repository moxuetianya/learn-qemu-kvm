## B. 关键术语

| 缩写 | 全称 | 含义 |
| --- | --- | --- |
| KVM | Kernel-based Virtual Machine | Linux 内核的虚拟化子系统 |
| QEMU | Quick EMUlator | 用户态虚拟机模拟器 |
| libvirt | – | 统一虚拟化 API |
| VMM / Hypervisor | Virtual Machine Monitor | 虚拟机监控器 |
| VMCS | Virtual Machine Control Structure | Intel VT-x 数据结构 |
| VMCB | Virtual Machine Control Block | AMD SVM 数据结构 |
| EPT | Extended Page Tables | Intel 二阶段页表 |
| NPT | Nested Page Tables | AMD 二阶段页表 |
| IOMMU | Input/Output Memory Management Unit | 设备 DMA 隔离 |
| VT-d | Intel Virtualization Technology for Directed I/O | Intel IOMMU |
| SR-IOV | Single Root I/O Virtualization | 网卡虚拟化 |
| VCPU | Virtual CPU | 虚拟 CPU |
| virtio | – | 半虚拟化 I/O 框架 |
| vhost | – | virtio 内核态后端 |
| IOVA | I/O Virtual Address | IOMMU 虚拟地址 |
| VGA | Video Graphics Array | 老式显卡 |
| QXL | – | QEMU 模拟的 2D 加速卡 |
| SPICE | Simple Protocol for Independent Computing Environments | 远程显示协议 |
| VNC | Virtual Network Computing | 远程桌面协议 |
| TCG | Tiny Code Generator | QEMU 动态指令翻译 |
| QCOW2 | QEMU Copy On Write version 2 | QEMU 镜像格式 |
| NUMA | Non-Uniform Memory Access | 非一致内存访问 |
| vCPUs | Virtual CPUs | 虚拟 CPU |
| VCPUs pinning | – | 把虚拟 CPU 绑到物理 CPU |
| VM exit | – | CPU 从客户机退出到宿主的硬件事件 |
| VM entry | – | CPU 进入客户机的硬件事件 |
| APICv | Advanced Programmable Interrupt Controller virtualization | 中断虚拟化硬件辅助 |
| Posted Interrupt | – | 中断直接投递客户机 |
| IOMMU group | – | 一组只能被一起透传的设备 |
| sVirt | – | libvirt 的 SELinux/AppArmor 沙箱 |
| HugePage | – | 大页（2MB 或 1GB） |
| DPDK | Data Plane Development Kit | Intel 数据平面开发套件 |
| OVS | Open vSwitch | 软件定义虚拟交换机 |
| VFIO | Virtual Function I/O | Linux 内核设备透传框架 |
| VF | Virtual Function | SR-IOV 虚拟功能 |
| PF | Physical Function | SR-IOV 物理功能 |
| microVM | – | 极简虚拟机（< 100ms 启动） |
| VDSM | – | oVirt 主机代理 |
| VDSM 监控 | – | 用 collectd 等收集 VM 指标 |
