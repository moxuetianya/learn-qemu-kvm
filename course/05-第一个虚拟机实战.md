# 05 · 第一个虚拟机实战

> 端到端把一台 VM 跑起来，含安装系统、网络通、SSH 登录。

## 学习目标

- 用 `qemu-img` 创建不同格式的磁盘镜像
- 用 `virt-install` 装一台 Alpine Linux 虚拟机
- 通过 NAT 网络 SSH 进去
- 用 cloud-init 做无人值守

## 1. 实验拓扑

```
你的电脑
   │
   │ SSH/VNC
   ▼
宿主 Linux (KVM) ── virbr0 (192.168.122.1/24, NAT)
                       │
                       ▼
                     VM (192.168.122.x)
                     alpine-virt
```

## 2. 三种启动方式对比

| 方式 | 何时用 | 难度 |
| --- | --- | --- |
| 直接 `qemu-system-...` 命令 | 学习底层 | ★★ |
| `virt-install` 命令行 | 自动化装机 | ★★ |
| `virt-manager` GUI | 桌面调试 | ★ |

## 3. 方式 A：直接 qemu 命令（教学）

### 3.1 准备磁盘

```bash
qemu-img create -f qcow2 /var/lib/libvirt/images/alpine.qcow2 4G
ls -lh /var/lib/libvirt/images/alpine.qcow2
# 注意：实际占用不会立刻是 4G，qcow2 稀疏
```

### 3.2 下载 Alpine ISO

```bash
cd /var/lib/libvirt/images
wget https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/x86_64/alpine-virt-3.20.3-x86_64.iso
```

### 3.3 启动 VM

```bash
qemu-system-x86_64 \
    -name alpine \
    -machine accel=kvm,type=q35 \
    -cpu host -smp 2 -m 1G \
    -drive file=alpine.qcow2,format=qcow2,if=virtio \
    -drive file=alpine-virt-3.20.3-x86_64.iso,media=cdrom,readonly \
    -netdev user,id=n0 \
    -device virtio-net-pci,netdev=n0 \
    -vnc :0
```

### 3.4 VNC 客户端连

```bash
# 命令行
vncviewer :0

# 或
virt-viewer :0
```

按 ISO 安装流程操作。

## 4. 方式 B：virt-install（推荐）

### 4.1 命令

```bash
sudo virt-install \
    --name alpine \
    --ram 1024 \
    --vcpus 2 \
    --disk size=4,format=qcow2,bus=virtio \
    --cdrom /var/lib/libvirt/images/alpine-virt-3.20.3-x86_64.iso \
    --network network=default,model=virtio \
    --graphics vnc,listen=0.0.0.0,port=5900 \
    --noautoconsole \
    --os-variant alpinelinux3.18
```

### 4.2 关键参数

| 参数 | 含义 |
| --- | --- |
| `--name` | VM 名 |
| `--ram 1024` | 内存 MB |
| `--vcpus 2` | vCPU 数 |
| `--disk size=4,format=qcow2,bus=virtio` | 4G qcow2 virtio 总线 |
| `--cdrom` | 启动 ISO |
| `--network network=default,model=virtio` | 接 libvirt default NAT 网，virtio 网卡 |
| `--graphics vnc,listen=0.0.0.0,port=5900` | VNC 端口 |
| `--noautoconsole` | 不绑当前终端 |

### 4.3 验证

```bash
virsh list                    # 看运行中的 VM
virsh dominfo alpine          # 看配置
virsh dumpxml alpine          # 看 XML
virsh console alpine          # 串口登录（要 OS 支持）
```

## 5. 方式 C：无人值守（cloud-init）

> 这是云时代标配：不用接 VNC，装完就能 SSH。

### 5.1 创建 cloud-init 配置

```bash
mkdir -p /tmp/cloud-init
cat > /tmp/cloud-init/user-data <<'EOF'
#cloud-config
hostname: alpine-demo
users:
  - name: peter
    sudo: ALL=(ALL) NOPASSWD:ALL
    shell: /bin/ash
    lock_passwd: false
    # 密码: alpine（生产用 ssh 密钥）
    passwd: "$6$rounds=4096$saltsalt$Z8wL.4Jv0z5wHjQwMTwMoqKj2lT8HOz4lzQ3WCZJYD/"
ssh_pwauth: true
package_update: true
runcmd:
  - apk update
  - apk add openssh qemu-guest-agent
  - rc-update add sshd default
  - rc-update add qemu-guest-agent default
EOF

cat > /tmp/cloud-init/meta-data <<'EOF'
instance-id: alpine-demo
local-hostname: alpine-demo
EOF
```

### 5.2 生成 cloud-init ISO

```bash
sudo apt install -y cloud-image-utils   # Debian/Ubuntu
# 或者
genisoimage -output /tmp/cloud-init.iso \
    -volid cidata -joliet -rock \
    /tmp/cloud-init/user-data \
    /tmp/cloud-init/meta-data
```

### 5.3 启动 VM（带 cloud-init ISO）

```bash
sudo virt-install \
    --name alpine-demo \
    --ram 1024 --vcpus 2 \
    --disk size=4,format=qcow2,bus=virtio \
    --cdrom /tmp/cloud-init.iso \
    --import  # 表示 vm 已有系统，避免再走 cdrom
    --os-variant alpinelinux3.18 \
    --network network=default,model=virtio \
    --graphics none \
    --noautoconsole
```

> ⚠️ `--import` 跳过「从 ISO 引导」。第一次装机需要走安装流程，之后可以 `--import` 直接跑磁盘镜像。

### 5.4 找出 VM IP 并 SSH

```bash
# 等 VM 起来后查 IP
virsh domifaddr alpine-demo
# 看到 192.168.122.x 即成功

ssh peter@192.168.122.x
# 密码 alpine
```

## 6. 常用管理命令

```bash
# 启停
virsh start alpine
virsh shutdown alpine          # ACPI 关机（优雅）
virsh destroy alpine           # 强制断电（拔电源）
virsh reboot alpine

# 编辑配置
virsh edit alpine              # 改 XML

# 删 VM
virsh undefine alpine          # 删定义（保留磁盘）
virsh undefine alpine --remove-all-storage  # 删定义 + 磁盘

# 查看统计
virsh domstats alpine
virsh domifstat alpine vnet0
```

## 7. 优劣对比：三种装机方式

| 维度 | qemu 直命令 | virt-install | cloud-init |
| --- | --- | --- | --- |
| 教学价值 | ✅ 最高 | ✅ 中 | ⚠️ |
| 自动化 | 手动 | 半自动 | 完全自动 |
| 可重复 | ❌ 每次重敲 | ✅ 脚本化 | ✅ 完全声明式 |
| 生产使用 | ❌ | ✅ 偶尔 | ✅ **云时代标配** |

> **生产建议**：本地调试 → qemu / virt-install；批量 / 云 → cloud-init 或 Packer / cloud-image。

## 8. 实战操作

完成下面实验：

### 8.1 用 qemu-img 创建三种格式

```bash
cd /tmp
qemu-img create -f raw      raw.img      1G
qemu-img create -f qcow2    qcow2.img    1G
qemu-img create -f vmdk     vmdk.img     1G
qemu-img create -f vdi      vdi.img      1G
ls -lh *.img
# 看实际占用（du 看真实）
du -h *.img
```

| 格式 | 谁用 | 优劣 |
| --- | --- | --- |
| raw | dd、libvirt、ovirt | ✅ 简单、性能最好<br>⚠️ 不支持快照、稀疏、压缩 |
| qcow2 | QEMU/KVM 默认 | ✅ 快照、压缩、AES 加密<br>⚠️ 性能略低于 raw |
| vmdk | VMware 兼容 | 兼容 VMware |
| vdi | VirtualBox 兼容 | 兼容 VBox |

### 8.2 装一台 Alpine

```bash
sudo virt-install --name alpine --ram 1024 --vcpus 2 \
    --disk size=4,format=qcow2,bus=virtio \
    --cdrom /var/lib/libvirt/images/alpine-virt-3.20.3-x86_64.iso \
    --network network=default,model=virtio \
    --graphics vnc,listen=127.0.0.1,port=5901 \
    --os-variant alpinelinux3.18 --noautoconsole

# VNC
vncviewer :5901
# 走完安装：setup-alpine，apk add openssh，rc-update add sshd
```

### 8.3 把它转成 cloud-init 镜像

把安装好的系统关机，导出成模板：

```bash
virsh shutdown alpine
# 等几秒
virsh domifaddr alpine       # 拿 IP

# 从源端 rsync 出完整系统
# 跳过，更省事：用 libguestfs 直接改磁盘
sudo virt-customize -a /var/lib/libvirt/images/alpine.qcow2 \
    --install openssh,qemu-guest-agent \
    --run-command 'rc-update add sshd default' \
    --run-command 'rc-update add qemu-guest-agent default'
```

### 8.4 测 SSH

```bash
ssh root@<ip>                 # 密码是你设置的
```

## 9. 小结

- 三种启动方式：qemu 命令、virt-install、cloud-init
- 镜像格式选择：qcow2 是 QEMU/KVM 事实标准
- **生产部署 = cloud-init + qcow2 模板**
